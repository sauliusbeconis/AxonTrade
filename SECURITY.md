# Security Policy

## Sensitive Data

Do not commit broker credentials, Rithmic credentials, API keys, account numbers, passwords, personal secrets, or private trading-account documents.

## Trading Safety

This repository is currently simulation-safe only. Live order routing is prohibited until a future explicit safety phase.

## Reporting Issues

Report security or trading-safety concerns through a private channel when available. If private reporting is not available, file a minimal public issue that does not disclose secrets or exploitable details.
